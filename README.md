# hayat-zaten-berbat
Hayat Zaten Berbat, Rafasilva'nın hikâyesini anlatan karanlık atmosferli bir pixel art macera oyunudur. Okul hayatı, zorbalık, yalnızlık, arkadaşlık, geçmiş anılar ve seçimlerle şekillenen farklı sonlar seni bekliyor.  Her seçim hikâyeyi değiştirir. Peki Rafasilva'nın hikâyesinin sonu nasıl olacak?
